# Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTeX в документации проекта

## Краткое описание

Данная лабораторная работа посвящена изучению языка разметки **Markdown** и базовому применению **LaTeX** для оформления документации проекта. В ходе работы были освоены заголовки, списки, таблицы, блоки кода, ссылки, изображения, чекбоксы, сноски, alert-блоки GitHub и математические формулы. Цель работы — научиться создавать структурированный и читаемый файл `README.md`, который демонстрирует владение всеми основными возможностями Markdown.

## Форматирование текста

- **Полужирный текст** — выделяет важные термины.
- *Курсив* — используется для акцентов.
- ~~Зачёркнутый текст~~ — отмечает устаревшее.
- `моноширный текст` — подходит для команд и кода.
