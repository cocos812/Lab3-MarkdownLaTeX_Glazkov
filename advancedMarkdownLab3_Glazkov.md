### Сноска

Markdown полезен в разработке[^dev].

[^dev]: Markdown упрощает совместную работу над документацией и интеграцию с CI/CD-пайплайнами.

### Alert-блок

> **TIP**: Для экранирования специальных символов в Markdown используйте обратный слэш `\`. Например, чтобы написать `*курсив*` без форматирования, напишите `\*курсив\*`.

### Escape-символы

- Заголовок без форматирования: \# я это не заголовок
- Звёздочка как текст: \*Просто звёздочки\*
