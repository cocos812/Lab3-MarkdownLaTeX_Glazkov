## Введение

Markdown — простой язык разметки для быстрого форматирования текста (заголовки, списки, жирный/курсив), легко преобразуемый в HTML. Применяется для документации, постов в блогах, веб‑контента; позволяет сосредоточиться на тексте, а не на сложном коде.

---

## Основные возможности Markdown

Быстрое и простое форматирование текста (заголовки, списки, ссылки, выделение) с сохранением читабельности для последующего преобразования в HTML/другие форматы. Идеален для документации, заметок, README‑файлов, блогов, сообщений. Синтаксис использует обычные символы вместо сложного кода — удобен и интуитивно понятен.

---

## Пример форматирования

### Заголовки

# Заголовок 1 (уровень H1)
## Заголовок 2 (уровень H2)
### Заголовок 3 (уровень H3)

### Выделение текста

**Жирный текст**  
*Курсивный текст*  
***Жирный и курсивный***
