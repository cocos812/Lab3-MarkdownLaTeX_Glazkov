## Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTeX в документации проекта
#### Что такое Markdown
Markdown — лёгкий язык разметки для оформления текстовых документов, преобразуемый в HTML/PDF; сохраняет читаемость в сыром виде.
#### Где применяется Markdown
GitHub (README), документация ПО, блоги, электронные письма, статические сайты, системы контроля версий, заметки.
#### Зачем нужен разработчикам
Быстрое создание структурированной документации, совместимость с CI/CD, единообразие форматов, экономия времени на верстку.
